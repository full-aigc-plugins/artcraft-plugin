## 1. 全局交互规则

沿用产品视觉 DNA。首版以宿主现有预览组件和原生编辑器为主，不要求另建 UI 页面。所有操作明确显示正在处理哪个项目、版本和产物。

## 2. 关键反馈文案

| 情况 | 用户反馈 | 下一步 |
| :--- | :--- | :--- |
| 运行时未安装 | 缺少已验证运行时，当前不会执行编辑 | 进入 setup 并显示来源与版本 |
| 结果不明确 | 正在核对上一次执行，不重复提交 | 查询或人工核对 |
| 证据过期 | 文件已变化，需要重新验收 | 重新检查当前版本 |
| 局部修改 | 显示修改范围与将重做的依赖 | 在现有授权内执行 |


## 3. 预览与可访问性

视频预览标注时间码、音轨与字幕版本；图片预览标注画幅与颜色空间；矢量预览附画板名称；工程链接与扁平导出分别列出。状态不仅用颜色表达，错误提供可复制代码及自然语言解释。

## 4. UI 验收边界

本次没有生成界面截图或声明原生应用 UI 通过验收。宿主安装和 bridge 行为在独立用例中记录；未来自有 UI 才增加模块 PRD/Stitch/UI 三件套。
