## 1. 需求来源与证据

已确认需求来自本次五插件规划及代表性验收任务；不是市场调研样本。目标用户是本地创作者与内容生产工程团队。尚未开展付费意愿访谈，不给出虚构的 TAM、SAM、SOM、价格或市场份额。

## 2. 问题与价值假设

| 问题 | 价值假设 | 验证方式 |
| :--- | :--- | :--- |
| 只能得到扁平成品 | 原生工程减少后续修改成本 | 验收时执行二次修改与重开 |
| 每次修改重做整个项目 | 版本依赖减少无关重算 | 比较变化前后实际执行节点 |
| 工具返回成功但文件不可用 | 独立验证减少错误交付 | 注入损坏输出并检查门禁 |


## 3. 相邻产品与集成策略

现有专业应用负责编辑引擎；Image Factory 和生成平台供应素材；Video Factory 提供适配范围内的确定性视频处理；剪映是可替代的原生剪辑目标；Content Factory 负责内容与渠道交付。ArtCraft 仅在混合场景承担项目编排。这里是职责比较，不是未经测量的性能排行。

## 4. 商业与采用决策

本阶段交付公开文档与规格，不建立收费分层。模型与云服务成本由实际供应商计费，并进入任务预算。是否商业发行及名称授权由维护者在 M4 前确认；这些条件不改变本地功能验收标准。
