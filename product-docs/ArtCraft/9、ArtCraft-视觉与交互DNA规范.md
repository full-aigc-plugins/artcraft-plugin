## 1. 交互载体

首版使用宿主对话、文件预览和上游原生应用。不新建 Web 编辑器。展示顺序为目标、输入、计划、执行进度、产物、验收及恢复动作。用户不需要理解内部模块名称才能做创作决定。

## 2. 状态与反馈

| 状态 | 必须展示 | 可执行动作 |
| :--- | :--- | :--- |
| 空项目 | 缺少的素材与交付目标 | 选择素材、填写目标 |
| 运行中 | 当前阶段和真实任务身份 | 查看进度、请求取消 |
| 失败或未知 | 已发生的动作与证据缺口 | 核对、恢复、修订 |
| 待审阅 | 原生工程、预览、缺陷与损失报告 | 接受当前版本或定点修改 |


## 3. 视觉与可访问性

宿主呈现采用清晰层级与浅色中性背景，状态同时使用文字和图标，不仅依赖颜色。长日志折叠，错误保留恢复入口。预览需标注画幅、版本和代理/正式状态。未来自有界面才应用 390×884、768×1024、1280×1024 的视口回归；本阶段没有自有响应式页面验收。
