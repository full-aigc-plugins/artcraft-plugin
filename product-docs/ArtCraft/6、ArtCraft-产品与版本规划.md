## 1. 产品与版本边界

当前 0.1.0-dev.7 是已发布开发快照，包含独立版本技能及可执行技术工作流；完整 P0、创作与生产验收仍待完成。V1 指目标功能范围，不是已发布版本。CLI 0.2.0 属于上游，不能与插件版本混淆。

## 2. 里程碑

| 阶段 | 交付 | 进入下一阶段条件 |
| :--- | :--- | :--- |
| D0 | 双语文档与 OpenSpec 基线 | 文档、链接、规范校验通过；实现任务仍未完成 |
| M1 | 独立技能与运行时适配 | 清洁环境安装、摘要检查、真实 MCP 调用 |
| M2 | 专业领域完整闭环 | 代表任务、工程重开、输出解码、局部修改 |
| M3 | ArtCraft 跨插件协作 | 版本传播、局部失效、断线恢复与幂等 |
| M4 | 宿主与发布验收 | 宿主实装与多平台证据；市场清单一致 |


## 3. 优先级与依赖

P0：独立技能、可信运行时、领域闭环、原生交付、恢复和基础安全。P1：新增平台、更多业务配方和额外生成服务。P2：性能优化与便利界面。ArtCraft 的真实联调依赖四个专业端达到 M2；它的公共协议设计不必等待领域实现。

## 4. 发布与停止条件

关键验收未通过不进入可安装市场。升级回退失败、原生格式损坏或重复付费提交是阻断缺陷。文档修订不消除未完成任务，禁止提前归档实现变更。
