# ArtCraft 默认 Python 首次使用架构

## 1. 规范与平台

沿用 OpenSpec AC-SK-003-PY 和任务 3.18。实际平台为 macOS arm64，使用现有 Homebrew Python 3.14.3，以 -I -B 调用。插件和技能源标签保持不变，本次交付验收工具与证据；其他 Python 版本和平台需单独验证。

## 2. 独立路径与身份

验证器先按固定宿主锁检查五个安装插件身份和 58 个技能摘要，再逐个复制到各自项目的 .agents/skills 下，每个项目只包含一个技能。目录来自真实 app-server 安装回执，不使用挂载点或猜测路径。缺少 Python、回执清单错误或安装元数据漂移时，在创建输出和安装原生依赖前拒绝。

```mermaid
flowchart LR
 H[固定宿主回执与锁] --> V[核验全部来源身份]
 V --> S[每个隔离项目仅复制一个技能]
 S --> P[现有默认 Python 与隔离参数]
 P --> C[本技能公开 CLI 启动器]
 C --> R[固定原生运行时]
 R --> T[严格版本与命令目录]
 T --> D[复核源安装和副本摘要]
```

## 3. 缓存与运行时

五领域分别建立全新缓存，各领域第一个技能执行公开在线冷安装，后续同领域入口复用已核验缓存；不能表述为 58 次独立冷下载。移除离线归档环境覆盖，原生子进程 PATH 仅含系统目录，不安装通用工具、Python 包或全局技能。ArtCraft --version 只安装编排运行时；创作工作流另按声明安装领域依赖。

## 4. 实际验证

58 个版本探测通过，耗时 42.371 秒。原生命令目录分别为 FilmCraft 666、EffectCraft 640、PhotoCraft 748、VectorCraft 585 项；数量不能证明每个命令的行为。ArtCraft 帮助包含 run 和 package。源安装和独立副本摘要均不变，副本没有字节码缓存。默认回归 48 项，44 项通过、4 项门禁跳过，耗时 2.666 秒；四项拒绝边界测试通过。

真实 Skills CLI／npx 安装保持 NOT_RUN；实际宿主安装后的默认 Python 原生混合工作流另行复验通过：2 项测试，耗时 49.322 秒。Homebrew Python 3.14.3 执行安装、五节点创作、品牌色返工、重复修订及打包，安装回执绑定该可执行文件。图像断言由测试专用 Python 3.13.5／Pillow 进程执行；混合运行后再次复核全部 58 个源安装与副本摘要。证据：docs/evidence/default-python-cli-first-use.json。

## 5. 边界

独立复制证明技能入口自包含，不证明外部 npx 安装器行为。命令目录与版本不证明创作交付、模型派发、GUI 或人工接受；这些范围需要单独证据。图像检查可以使用测试专用 Pillow 环境，但必须明确它与工作流运行时的区别，不能将其暗中变成运行依赖。
