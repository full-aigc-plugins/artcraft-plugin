> **最后更新**：2026-10-05
> **状态**：目标设计；尚未实现。事实依据与验收结果单独标注。

## 1. 规范事实源与执行边界

[OpenSpec tasks](../openspec/changes/establish-v1-plugin/tasks.md)

任务当前全部未实施。先失败测试、再最小实现、再真实证据。技能包与运行时分别发布；只有插件与市场元数据同步且宿主验收通过后才可供安装。

## 2. 实施顺序与责任

| 阶段 | 交付 | 进入下一阶段条件 |
| :--- | :--- | :--- |
| D0 | 双语文档与 OpenSpec 基线 | 文档、链接、规范校验通过；实现任务仍未完成 |
| M1 | 独立技能与运行时适配 | 清洁环境安装、摘要检查、真实 MCP 调用 |
| M2 | 专业领域完整闭环 | 代表任务、工程重开、输出解码、局部修改 |
| M3 | ArtCraft 跨插件协作 | 版本传播、局部失效、断线恢复与幂等 |
| M4 | 宿主与发布验收 | 宿主实装与多平台证据；市场清单一致 |

## 3. 验收 fixture 与证据包

完成品牌图形、海报、动态片头与宣传片；替换 Logo 后仅更新依赖它的产物；中断恢复不重复提交已发生的生成任务。

fixture 使用自有或可再分发素材，记录来源与摘要。证据包包括输入清单、计划、运行身份、任务账本、原生工程、重开检查、导出与损失报告。重复测试使用新工作目录，保留前轮产物用于差异分析。

## 4. 提测与失败注入

| 用例 | 预期 |
| :--- | :--- |
| 错误摘要安装包 | 拒绝安装，旧版本仍可用 |
| 提交后终止进程 | 进入核对，不盲目重做 |
| 输出同名替换 | 验收过期 |
| GUI 并发修改 | 版本冲突，不覆盖 |
| 取消后迟到结果 | 记录孤立产物，不提升状态 |

## 5. 运维与回退

先检查运行身份、授权范围、计划摘要与工程版本，再判断错误。unknown 结果保留工作目录和账本，查询原任务或核验原生产物。升级前排空并备份，失败恢复已验证组合；不兼容 schema 回退需从备份恢复。卸载仅移除插件自身缓存，用户工程与素材默认保留。

## 6. 发布与完成定义

P0 需求全部有可复现证据；所有任务已验证后勾选；技能锁、运行时锁、宿主清单和市场版本一致；干净环境安装成功；英文与中文描述一致；未支持的平台和模式明确列出。随后执行 OpenSpec verify 或等价检查，再同步与归档；不得因为文档齐全就提前归档。
