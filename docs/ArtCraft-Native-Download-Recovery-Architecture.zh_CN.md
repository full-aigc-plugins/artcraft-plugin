# ArtCraft 原生首次安装恢复

Art包下载已经支持有限重试，但领域原生安装子进程此前只下载一次。Art80冷安装因EffectCraft原生下载SSL EOF失败。现在通过不可变Film18／Effect、Photo、Vector17完整技能源包收录原生安装器恢复行为，runtime78字节保持一致。

```mermaid
flowchart LR
    A[单个Art技能] --> B[固定Art及领域技能源包]
    B --> C[领域安装子进程]
    C --> D[最多三次只读下载]
    D --> E[摘要及原生版本]
    E --> F[独立原生安装]
```

分发合同以逐文件摘要绑定全部48个领域安装器、完整命令入口和协议客户端；重试前丢弃半包。证书、权限、尺寸和摘要错误不变为可重试错误，原生编辑请求不被重放。

新固定源及插件须通过十个独立技能分别公开冷安装四领域、实际捆绑包原生保存故障、混合HD创建／返工／恢复、移动包、安装摘要保全及精确提交CI。候选及原生验证通过与Art80冷安装失败分别保留证据。OpenSpec4.10在这些检查通过前保持开放；2639条命令逐项、GUI、模型及完整V1门禁另行管理。

固定发布状态更新：新的macOS arm64安装与原生子门禁通过，未覆盖全部命令、GUI、模型及完整V1。 [Evidence](evidence/codex-native-download-first-use-20261007.json).
