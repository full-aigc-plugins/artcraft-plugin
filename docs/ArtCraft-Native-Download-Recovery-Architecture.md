# ArtCraft native first-use recovery

Art package downloads already had bounded retries, but domain native installers ran a single download attempt in a subprocess. Art80 cold installation failed on an EffectCraft native SSL EOF. Domain bootstrap recovery is now included through new immutable Film18 / Effect, Photo, Vector17 source bundles. Runtime78 remains byte-identical.

```mermaid
flowchart LR
    A[Single Art skill] --> B[Fixed Art and domain source packages]
    B --> C[Domain bootstrap subprocess]
    C --> D[Three read-only download attempts]
    D --> E[Hashes and native version]
    E --> F[Independent native installation]
```

The distribution contract binds all48 native installers, complete-command clients and protocol clients by per-file hashes. Partial downloads are discarded. Certificate, permission, size and checksum failures do not become retryable; native edit requests are never replayed.

A new fixed source and plugin must pass ten independent all-domain cold installations, installed bundle native save faults, mixed HD creation/revision/recovery, a moved package, immutable installed files and exact-commit CI. Earlier candidate/native passes and Art80 cold failures are distinct evidence. OpenSpec4.10 remains open until these checks pass. Exhaustive2639-command, GUI, model and fullV1 gates remain separate.
