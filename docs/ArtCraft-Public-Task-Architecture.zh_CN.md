# ArtCraft 公共任务协议实施审计

规格事实源仍为 OpenSpec 变更 `establish-v1-plugin`。本次审计完成实施任务 **1.1、1.2**；真实边界验收 **1.3 保持开放**。本次未改变运行时、技能快照、协议 schema 或发行身份。

## 请求、执行与响应

```mermaid
flowchart LR
    Request[版本化请求] --> Schema[严格核心字段与 JSON 校验]
    Schema --> Binding[规范化计划与分区身份绑定]
    Binding --> Ledger[SQLite 持久任务]
    Ledger --> Authorization[已有授权范围]
    Authorization --> Runtime[运行时身份与工程版本核对]
    Runtime --> Worker[受监督执行]
    Worker --> Verify[进程停止与产物核验]
    Verify --> Receipt[当前持久任务回执]
    Schema -->|无效| Reject[副作用前结构化拒绝]
    Binding -->|冲突| Reject
    Authorization -->|超出范围| Reject
    Worker -->|结果未知| Reconcile[保留 attempt 与占用]
```

登记返回 `planned`，attempt 为 null；取得执行权后进入 `running` 并创建 attempt。`review_ready` 需要技术核验，不代表创作通过或 `completed`。工作流节点摘要公开当前账本回执，不构造第二套任务身份。复用读取原任务；登记前拒绝不得伪造任务回执。
