# Contributing / 贡献

This repository currently delivers documentation and OpenSpec planning artifacts. Product behavior is not implemented.
本仓当前交付文档与 OpenSpec 规划，产品行为尚未实现。

1. Read AGENTS.md, the bilingual README, and the active OpenSpec change.
2. Propose behavioral changes in OpenSpec before implementation; retain one normative source.
3. Keep English and Chinese explanations equivalent; identifiers and commands must match.
4. Maintain skills in their independent source package, then pin immutable snapshots here.
5. Validate document links, requirement/task coverage and strict OpenSpec syntax.
6. Mark implementation tasks complete only with actual test and artifact evidence.
7. Do not add a marketplace entry or release badge before host and native-workflow acceptance.

Report documentation defects through repository issues. Do not post credentials or private user media.
